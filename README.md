# BARRY · Testversion – Installation

BARRY ist eine Web-App. Sie wird über den Link installiert, nicht über einen App-Store. Nach dem ersten Öffnen funktioniert sie auch offline.

**Link:** [LINK EINSETZEN]

## Installieren
**Android (Chrome):** Link öffnen → Menü ⋮ oben rechts → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ → bestätigen.

**iPhone/iPad (nur Safari):** Link öffnen → Teilen-Symbol □↑ → „Zum Home-Bildschirm“ → „Hinzufügen“.

**PC/Mac (Chrome oder Edge):** Link öffnen → Installieren-Symbol rechts in der Adressleiste → „Installieren“.

Danach BARRY immer über das neue Symbol auf dem Startbildschirm öffnen.

## Erste Anmeldung
1. Name **Admin**, Passwort **admin** eingeben.
2. Eigenes Passwort vergeben.
3. Unter „Verwaltung“ die eigene Staffel, Personen und Hunde anlegen.

## Wichtig
- Alle Daten bleiben ausschließlich auf diesem Gerät. Es gibt keinen Server und keine Übertragung an Dritte.
- Regelmäßig über „Jetzt sichern“ eine Datensicherung erstellen. Ohne Sicherung gehen die Daten verloren, wenn Browserdaten gelöscht oder das Gerät gewechselt wird.
- Die heruntergeladene HTML-Datei per Doppelklick zu öffnen ist zum Anschauen möglich. Installierbar ist BARRY aber nur über den Link.
- Updates: Bei einer neuen Version erscheint ein Hinweis zum Neuladen.
